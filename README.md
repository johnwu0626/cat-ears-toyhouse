# 桌底的貓耳：立體玩具屋抓貓大作戰

以立體玩具屋為舞台的抓貓遊戲，提供六個房間、三種貓咪，以及潛行、衝刺、體力、警戒與毛線球引誘。

## 試玩

下載並以支援 WebGL 的瀏覽器開啟根目錄的 `index.html`。程式、樣式與繪圖程式庫均已內嵌，可獨立開啟，也可放在靜態網站伺服器上。

將檔案存放到 GitHub 儲存庫，與啟用 GitHub Pages 網站是兩個步驟；此專案未自動設定發布流程。

## 操作

- 點擊走道或按住拖曳移動；電腦也可使用 WASD 或方向鍵。
- 按住「衝刺」或 Shift 加速，會消耗體力並增加聲響。
- 點「潛行」或按 C 切換安靜移動。
- 選「毛線球」或按 E，再點地板投放，每局三顆。
- 點暫停按鈕或按 Escape 暫停。

貓咪會警戒、逃跑、假轉向與休息。預判逃跑路線可以快速攔截；遊戲保留這項玩法。最快紀錄只儲存在目前使用的瀏覽器。

## 原始碼

- `index.html`：最新版、可獨立執行的整合成品。
- `src/index.html` 與 `src/styles.css`：介面與排版。
- `src/app.js`：輸入操作與介面整合。
- `src/game-core.js`：碰撞、路徑、貓咪行為、資源與計時。
- `src/toy-renderer.js`：立體模型、燈光、動畫與點擊座標轉換。
- `src/vendor/`：Three.js 繪圖程式庫及其 MIT 授權。

模組化原始碼入口為 `src/index.html`，供透過本機 HTTP 伺服器預覽及編輯。根目錄整合成品需在原始碼變更後重新打包；此儲存庫未包含打包工具。

## 驗證範圍

來源版本的核心與動態測試共 17 項通過，涵蓋加速、體力、碰撞、暫停、重開與捕獲。瀏覽器已檢查開始、潛行、衝刺、引誘、結算與手機直式排版。

手機可使用觸控操作；目前場景在直式畫面偏小，尚未在實體 iPhone 或 Android 測試效能與多指操作。
